## Описание проекта

    В проекте осуществляется сбор данных о вакансиях:

    Собранные данные сохраняются для обзора/анализа в разрезе времени.

    Союирается и отображается как количество вакансий, грейды, ключевые 
    скилы, зарплаты (минимальные/максимальные)

    Отображение данных о вакансиях осуществляется по различным периодам 
    времени и грейдам.


## Техническое описание проекта

    Данные с hh.ru собираются по средствам api, через библиотеку request.
    Сохранение данных происходит в pandas.

    Отображение происходит по средствам библиотеки [dash](https://dash.plotly.com/)
